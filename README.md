# bmstu-os-coursework
coursework by operation system

Разработать модуль ядра Linux для мониторинга использования разделяемой памяти (Shared Memory) процессами. Реализовать отслеживание создания, подключения, отключения и удаления сегментов памяти, сбор информации об их характеристиках и статистике использования. Также реализовать мониторинг каналов межпроцессного взаимодействия (pipes), включая отслеживание их создания, использования и закрытия. Разработать пользовательскую утилиту для отображения собранных данных. Провести тестирование корректности работы и оценить влияние мониторинга на производительность системы.
